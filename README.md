# Cadence

The interface uses a premium editorial visual system: DM Serif Display and DM Sans typography, restrained violet accents, layered dark surfaces, balanced spacing, refined controls, and a separately styled light theme. The redesign is a CSS and presentation-layer update; the existing React features and local storage logic are retained.

A local-first communication, speaking and rhetoric practice app built with React, TypeScript and Vite.

## Run locally

```bash
npm install
npm run dev
```

Production build: `npm run build`. Deploy the project folder to Vercel; `vercel.json` supports the single-page app.

## Main areas

- **Home:** random speaking practice only, with Off the cuff, Extended and Deep research modes, category filter, topic spinner, timer and recording.
- **Debate:** proposition/opposition, notes and structured debate rounds.
- **Exercises:** dedicated pages for Q&A, Explain Anything, Storytelling, Summarisation, Conciseness, Conversation, Active Listening, Question Crafting, Presentation, Interview, Real-life Scenarios, Rhetoric & Persuasion, Movie & Book Explanation, Argue Both Sides and Vocabulary.
- **Topics:** add one topic or paste a set. Bulk entry creates a separate editable row for every topic. Each row must be classified with a category, mode, difficulty and one or more exercise tags before it is saved.
- **Progress:** lifetime timer minutes and saved self-assessment summaries.
- **Library:** locally stored recordings with playback, rename, delete and export.

## Topic classification rules

- **Off the cuff:** familiar, everyday subjects; no research expected.
- **Extended:** niche or specialised subjects; independent thinking, optional reading.
- **Deep research:** research-worthy topics where sources and preparation are expected.

Every user-added topic has an explicit category, mode, difficulty and exercise assignment. The Home spinner filters by mode and category, avoids recent topic IDs, and never selects a topic from another mode. Exercise pages select from topics tagged for that exercise. A topic can be tagged for multiple exercises.

## Storage and privacy

User-added topics, recent topics, theme and custom questions are stored in browser localStorage. Audio recordings use IndexedDB (the existing `unprompted-local` database name is retained so existing recordings from the previous build remain available on the same browser origin). Clearing site data can erase local content; export important recordings. No account, backend or paid API is required.

Audio export uses the browser's actual recording format; WebM is never renamed to M4A. Genuine M4A/AAC depends on browser MediaRecorder support. Microphone access requires permission and HTTPS or localhost. There is no live AI debate opponent or automatic transcription in this offline version.

## Included topic data

The earlier generated topic bank and supplemental `public/data/20000_speaking_topics.csv` are retained. New topics added through Cadence use the strict classification workflow described above.


## Speaking Studio interface update

The home page now uses an immersive, focused speaking-studio layout inspired by the supplied references, while retaining Cadence's violet palette. The main navigation is Practice, Debate, and Exercises. The gear menu contains Topic Library, Progress, Recording Library, timer duration, speaking framework, timer sound, and appearance controls. Starting a timer opens a focused full-screen session view with What / So what / Now what speaking stages.


## Noir Glass update

- Four persistent color packs: Forest Green, Amethyst Purple, Space Navy and Champagne Amber.
- Emoji-led topic categories; topic cards do not require thumbnail images.
- Framework-aware timer for PREP, PEEL, What–Why–How, Past–Present–Future, Problem–Cause–Solution, 5W1H, Pros and Cons, STAR, Claim–Evidence–Reasoning and First Principles.

- The active framework phase and its cue are shown directly below the main countdown.
- Theme and phase timing preferences persist in local storage. Existing IndexedDB recording storage and the topic CSV are retained.
